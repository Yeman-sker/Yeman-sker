### 🔭 Flagship — [Loupe](https://github.com/Yeman-sker/Loupe)

> Pin a real DOM element in your browser, hand the exact target + context to an AI coding agent (Claude Code / Codex) via MCP, and resolve.

A local-first Chrome MV3 extension + daemon + MCP bridge that turns *"the blue button top-right"* into a **structured, recoverable, project-scoped mark**. The trust loop: `pick → locate → persist → resolve`.

- **6-package monorepo** (extension, daemon, shared schema, Claude plugin, Codex plugin, E2E tests)
- Robust multi-evidence locator with drift detection — shows `drifted` / `lost`, never a silent wrong pick
- Token-guarded loopback daemon; MAIN world stays read-only
- Full PRD, architecture decision records, phased delivery docs

🛠️ `TypeScript` · `Chrome MV3` · `MCP` · `pnpm` · `Playwright`
